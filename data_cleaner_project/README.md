# 🧹 Automated Data Cleaning & Visualization Tool

This project automatically cleans, summarizes, and visualizes datasets (CSV or Excel).  
It’s ideal for clients who need fast, clear, and interactive reports without manual data prep.

## 🚀 Features
- Cleans messy data (missing values, duplicates, inconsistent formatting)
- Generates interactive histograms and heatmaps
- Produces an all-in-one **HTML report** with embedded charts
- Saves a cleaned CSV for further use

## 🧠 Tech Stack
- Python  
- pandas, numpy  
- plotly.express  

## 📁 Output Files
- `cleaned_data.csv` — cleaned dataset  
- `report_summary.html` — interactive visualization report  

## 🧰 Usage
```bash
python data_cleaner.py <input_file.csv>
